# Forum — Flutter Messenger

Мессенджер **Forum** на Flutter, повторяющий дизайн из Figma (вкладка "web step"):
двухпанельный веб/десктоп‑интерфейс — список диалогов слева и переписка справа,
тёмная и светлая темы, фиолетовый акцент `#904FFF` и лаймовый `#9BFF4B`.

## Возможности

- Список диалогов: поиск, фильтры (Все / ИИ / Личное / Коллеги) со счётчиками,
  аватары с градиентом или фото, бейджи непрочитанного, индикаторы статуса,
  закрепление, mute, онлайн, избранное.
- Переписка в стиле ленты (thread): имена отправителей цветом, аватары, дата‑разделители,
  галочки статуса, цитирование, реакции‑эмодзи.
- Типы сообщений: текст, медиа (с бейджем длительности), файл, голосовое
  (с гистограммой), геопозиция.
- Адаптивный layout: широкий экран — две панели; узкий — список/переписка по одному.
- Переключение темы (кнопка в шапке списка).

## Модели данных

Порт Swift‑структур из ТЗ (`lib/models/`):

| Swift                      | Dart                                   |
| -------------------------- | -------------------------------------- |
| `DialogsListViewModel`     | `dialogs_list_view_model.dart`         |
| `MessageViewModel`         | `message_view_model.dart` (+ `MsgSize`)|
| `MediaFile`                | `media_file.dart`                      |
| `MessageEmojiModel`        | `message_emoji_model.dart`             |
| `ChatType`                 | `chat_type.dart`                       |
| `GroupAditionalInfoModel`  | `group_additional_info_model.dart`     |

Имена полей сохранены как в оригинале (`last_msg`, `prn_*`, `fr_id`, `dttmcr` и т. д.).
`CGSize` → `MsgSize`, `Int64` → `int`, `URL?` → `String?`.

## Структура

```
lib/
  main.dart                 # точка входа, темы, Provider
  models/                   # 6 моделей данных
  theme/                    # токены цветов и ThemeData (тёмная/светлая)
  state/app_state.dart      # ChangeNotifier: тема, выбор чата, отправка
  data/mock_data.dart       # демо-данные
  screens/home_screen.dart  # адаптивный двухпанельный экран
  widgets/                  # sidebar, тайлы, переписка, сообщения и т.д.
```

## Запуск

Требуется установленный Flutter SDK (>= 3.10).

```bash
flutter pub get

# Веб (рекомендуется — это "web step"):
flutter run -d chrome

# Десктоп (macOS):
flutter run -d macos
```

> Перед первым запуском на конкретной платформе может потребоваться
> `flutter create .` в папке проекта, чтобы сгенерировать платформенные папки
> (`web/`, `macos/`, и т. д.) — исходный код в `lib/` при этом не затрагивается.

## Заметки

- Реальные фото/медиа в демо отсутствуют, поэтому аватары и вложения
  отображаются как градиентные плейсхолдеры с инициалами/иконками.
- Это UI‑прототип с локальным состоянием и мок‑данными, без реального бэкенда.
